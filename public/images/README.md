# Landing page images

Put your **landing background image** here.

- **File name in use:** `ft-background.jpg` (or `ft-background.png` — if you use .png, the path in `App.css` `.landing-page` must be updated to `/images/ft-background.png`).
- The app uses `/images/ft-background.jpg` for the full-screen landing background.
- Suggested size: 1920×1080 or larger; the image is set to `background-size: cover`.
